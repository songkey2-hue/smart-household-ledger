# 💳 스마트 머니로그 (Smart MoneyLog) - 웹 가계부 앱

> **한국금융연수원 '바이브 코딩 활용 풀스택 서비스 개발' 실기평가 자유과제 포트폴리오**  
> GitHub Repository 및 Vercel 클라우드 글로벌 배포 최적화 프로젝트

---

## 🌟 프로젝트 소개
**스마트 머니로그**는 별도의 무거운 앱 설치나 서버 설정 없이 브라우저에서 바로 수입·지출을 기록하고, 예산 소진율과 카테고리별 소비 비중을 한눈에 파악할 수 있는 반응형 웹 가계부입니다.

- **라이브 배포**: Vercel Global Edge CDN 지원
- **데이터 보존**: Web Storage (`localStorage`) 기반 영구 저장
- **모바일/데스크톱 반응형**: 스마트폰, 태블릿, PC 등 모든 해상도 지원

---

## 🚀 핵심 기능

1. **초간편 수입/지출 등록 (CRUD)**
   - 수입 / 지출 탭 원클릭 전환
   - 카테고리(식비, 교통, 주거, 급여 등), 사용처, 금액, 메모 입력
   - 즉각적인 리스트 렌더링 및 개별 내역 삭제
2. **금융 요약 대시보드**
   - 당월 총 수입 / 총 지출 / 순 잔액(수지차) 실시간 계산
   - 당월 설정 예산 대비 소진율(%) 및 컬러 게이지 프로그레스 바
3. **카테고리별 소비 점유율 분석**
   - 카테고리별 지출 금액 순 자동 정렬 및 점유율(%) 시각화 바 제공
4. **월별 이동 및 정밀 필터링**
   - 이전 달 / 다음 달 / 이번 달 이동 컨트롤러
   - 전체 / 지출만 / 수입만 탭 필터 및 실시간 텍스트 검색
5. **데이터 백업 및 시연 편의 기능**
   - **[샘플 데이터 채우기]**: 평가 시연을 위한 표준 직장인 금융 데이터 1-클릭 로드
   - **[CSV 내보내기]**: 엑셀 한글 깨짐 방지(UTF-8 BOM)가 적용된 CSV 파일 다운로드
   - **[백업]**: JSON 형식 전체 데이터 내보내기

## 🛠️ 기술 스택 및 구조
- **Frontend**: HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Storage**: Browser LocalStorage
- **Deployment**: GitHub + Vercel (Zero Config Static Web Hosting)
